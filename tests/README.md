# دليل ملفات الاختبارات
# سيتم إضافة ملفات الاختبارات هنا مستقبلاً

## أنواع الاختبارات المطلوبة:

### 1. اختبارات الوحدات (Unit Tests)
- اختبار وحدات التحقق من البيانات (validation.js)
- اختبار وحدات التصدير (export.js)
- اختبار وحدات النسخ الاحتياطي (backup.js)
- اختبار وحدات الإشعارات (notifications.js)
- اختبار وحدات الثيم (theme.js)

### 2. اختبارات التكامل (Integration Tests)
- اختبار التكامل مع Firebase
- اختبار التكامل مع Google OAuth
- اختبار التكامل مع واجهة المستخدم

### 3. اختبارات الواجهة (UI Tests)
- اختبار صفحات HTML
- اختبار التفاعل مع النماذج
- اختبار الاستجابة للشاشات المختلفة

## أدوات الاختبار المقترحة:
- Jest للاختبارات الأساسية
- Testing Library لاختبارات الواجهة
- Cypress للاختبارات الشاملة

## تشغيل الاختبارات:
```bash
npm test
```
